## Project Overview

This project is designed to help instructors in COSC 4P02 check students’ code submissions for academic integrity. The system allows students to upload assignments written in C, C++, or Java. It stores these assignments in repositories and analyzes them to find similarities between submissions from current and past semesters, or other selected code bases.

The system anonymizes submissions to protect student privacy and provides instructors with a clear, web-based interface to review similarity reports.

---

## Features

- Web-based submission system for code assignments  
- Repository management for storing current and past submissions  
- Custom-built code similarity analysis engine (no AI used) for C, C++, and Java  
- Anonymization of student information to protect privacy  
- Instructor dashboard to view similarity scores and compare code side-by-side
